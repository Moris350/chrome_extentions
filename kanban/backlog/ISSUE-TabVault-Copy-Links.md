# Issue Description
Users often want to share their saved tab vaults in Notion or Slack. To make this easier, we should add a 'Copy All Links' button to each saved vault. When clicked, it should copy all the tabs' URLs to the user's clipboard using 
avigator.clipboard.writeText.

# Acceptance Criteria
- [ ] 'Copy All Links' button added to each saved vault item in the UI.
- [ ] Clicking the button copies all tab titles and URLs to the clipboard.

# ISSUE-001: Research Chrome Web Store for extension opportunities

## Description

Research the Chrome Web Store to identify profitable extension niches with high demand and low-to-medium competition. Focus on categories where Freemium model works well.

## Acceptance Criteria

- [ ] Identify at least 5 extension categories with high demand
- [ ] For each category, list top 3-5 competitors (name, installs, rating, pricing)
- [ ] Identify gaps and pain points from competitor reviews
- [ ] Score each opportunity using ICE framework (Impact × Confidence × Ease)
- [ ] Recommend top 3 extension ideas with justification
- [ ] Document findings in `docs/research/market-research-v1.md`

## Research Areas

- Productivity (tab management, bookmarks, automation)
- Developer tools (API testing, debugging, code helpers)
- Social media (schedulers, analytics, downloaders)
- Privacy & security (ad blocking, tracking protection)
- Shopping (price trackers, coupon finders)
- Content (screenshots, note-taking, readers)

## Notes

- Focus on niches where existing extensions have >10K installs but <4.0 rating (room for improvement)
- Prefer categories where premium features are a natural upsell
- Avoid categories with dominant free players (e.g., ad blockers)

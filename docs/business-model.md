# Business Model — Chrome Extensions Freemium

## Revenue Model

### Free Tier
- Core functionality available to all users
- No time limit, no registration required
- Serves as user acquisition and trust building

### Premium Tier
- Advanced features unlocked via payment
- **Pricing options** (per extension):
  - One-time purchase: $4.99 – $14.99
  - Monthly subscription: $1.99 – $4.99/mo
  - Annual subscription: $14.99 – $39.99/yr (2 months free)

### Revenue Targets
| Timeline | Extensions | Installs | MRR Target |
|----------|-----------|----------|------------|
| Month 1-2 | 1 MVP | 500 | $0 (free only) |
| Month 3-4 | 2 extensions | 2,000 | $200 |
| Month 5-6 | 3 extensions | 5,000 | $500 |
| Month 7-12 | 5 extensions | 15,000 | $1,500 |

## Cost Structure

| Item | Monthly Cost | Notes |
|------|-------------|-------|
| Chrome Web Store Developer | $5 (one-time) | Registration fee |
| Domain + Hosting | $0-10 | Cloudflare free tier covers most |
| Payment Provider | 5-8% per transaction | LemonSqueezy / Stripe |
| Backend Hosting | $0-5 | Cloudflare Workers free tier |
| Database | $0-5 | Supabase free tier |
| **Total Fixed** | **~$10/mo** | |

## Key Metrics to Track

1. **Install Rate**: Daily new installs per extension
2. **Retention**: DAU/MAU ratio
3. **Conversion Rate**: Free → Premium (target: 3-5%)
4. **ARPU**: Average Revenue Per User
5. **Churn Rate**: Monthly premium cancellations
6. **Store Rating**: Target > 4.5 stars
7. **Review Volume**: Indicates engagement

## Competitive Advantages

1. **Speed**: AI-powered development = faster iteration
2. **Quality**: Automated testing + structured QA process
3. **SEO**: Optimized store listings from day one
4. **Data-Driven**: Analytics-informed feature decisions
5. **Low Overhead**: Minimal human involvement = higher margins
